大厂动态 · Agent 治理影响★★★★★

AI Agent 基础设施集中补课：Google 微虚拟机、1Password 代登录、大银行封堵

Google 推出 Agent Compute Engine，为每个 Gemini Agent 分配硬件隔离的微虚拟机；1Password 允许 Agent 代用户登录而不暴露密码；但美国主要银行开始封禁使用客户凭证登录的 AI Agent。Agent 的运行时安全与身份权限成为规模化落地核心矛盾。

为何重要：Agent 从 demo 走向生产的关键卡点

落地启发：企业部署 Agent 需优先设计隔离运行时与最小权限凭证

今日趋势点评

行业大势

资本正加速向头部模型公司集中，但估值分歧与 IPO 窗口同步逼近。

今日 OpenAI 推进 300 亿美元融资、估值 1.25 万亿美元，同时 DeepSeek 完成近 1000 亿元融资，宁德时代、腾讯参投；但 OpenAI 被曝下调估值目标，显示资本方对天价估值并非一致看多。

💡 建议：投资者应关注头部融资对二级市场 AI 资产的抽水效应；创业公司需在 IPO 窗口关闭前证明独立造血能力。

落地应用启发

Agent 规模化的瓶颈已从模型能力转向运行时安全与身份权限。

Google 为每个 Gemini Agent 分配硬件隔离微虚拟机，1Password 推出 Agent 代登录，而美国大银行开始封堵 Agent 使用客户凭证登录；Gartner 调查显示仅 13% 企业获得真实 AI 回报。

💡 建议：企业部署 Agent 应优先建设隔离运行时、最小权限凭证与审计日志，避免因安全事件导致项目回滚。

对国内中小企业的影响

国产模型以极致性价比切入多模态与决策场景，降低应用门槛。

Kimi K3.1 的 3D 生成成本仅为 GPT-6 Astra 的 1/14，蚂蚁数科决策模型准确率超微软与 Jev，中电信开源 29B 意图模型，叠加 DeepSeek 巨额融资后的算力储备。

💡 建议：中小企业可优先测试国产开源模型替代方案，把节省的推理成本投入数据治理与场景闭环。
