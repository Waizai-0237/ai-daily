今日趋势点评

行业大势

资本正从模型层转向基础设施与安全层，估值逻辑重估。

纳斯达克因AI抛售回吐全年涨幅，Anthropic上市次日遇冷；同时华为云开放昇腾底座、OpenAI强化反蒸馏，显示资金与注意力向算力自主与安全能力集中。

💡 建议：投资者应增配算力基建与安全赛道，企业需将安全合规纳入核心成本。

落地应用启发

设备级 Agent 成为巨头入口争夺焦点，隐私隔离是落地前提。

苹果招聘工程师自研可跨应用操作的 Agent；Signal 限制截图防止 Gemini/Siri 读取私聊；Gemini 已可后台运行 Mac 应用。

💡 建议：Agent 开发者应内置隐私沙盒与用户授权机制，避免合规风险。

对国内中小企业的影响

国产算力开放降低具身智能门槛，多维竞争替代单一芯片比拼。

昇腾算力训出双榜 SOTA 具身世界模型，华为云开放整套底座；Agnes 开源将 Agent 成本降至1/27。

💡 建议：中小企业可基于开放底座快速验证场景，聚焦数据与落地速度构建壁垒。
